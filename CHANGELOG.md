# Changelog

## 1.2.1 — 2026-08-12

First stable OreoFlow framework release.

- Publish the stable `oreoflow` Python import surface.
- Provide role-based Pollinations routing, streaming, tool schemas, budgets, and token ledgers.

- Add OpenAI Responses effort integration used by Search.
- Pin the frontend and Python distribution to one repository release version.
- Improve documentation code panels with copy controls, labels, and line numbers.
